# 产品契约

gait 是按需使用 Git 工具的通用 Agent。一次调用接收一个完整请求，输出一次最终回复后退出。下次调用不读取前文；不提供连续会话或历史存储。模型连接配置可以持久保存。

使用与配置见 [README](../README.md)，输入入口见 [application.norm](../gait/application.norm)，工具能力见 [tools.norm](../gait/tools.norm)。

- 普通回答不需要 Git；仓库事实通过工具取得。
- 用户提出目标后，Agent 尽可能自行完成必要步骤。提交默认按内聚主题分批，自行生成提交信息；具体范围、暂存边界和阻碍引导以 [行为指令](../gait/instructions.norm) 为准。
- 一次请求内可以多次调用工具。模型文本增量立即显示，不缓存到生成结束或人工延时；完整文本在完成事件到达时不重复打印。回答依据实际工具结果生成。
- 工具参数严格解码，执行复用 Git 前置检查和写后验证，不接受模型生成的 Shell。
- 工具失败回传模型，已发生的外部效果不宣称回滚，不自动重试结果未知的写操作。
- JSON 模式返回一个结果，包含最终文本和工具结果；运行错误返回具体错误，不声称此前未执行操作。
- 内存上下文随本次进程结束而释放，不读取或写入会话文件，也不通过响应 ID 恢复服务端历史。
- 优先通过单文件定向总结了解文件，必要时分页读取原文。本次上下文过长时压缩工作记录，并保留原始目标和操作结果；压缩记录不落盘。
